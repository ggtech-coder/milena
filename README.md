# MILENA — frontend corrigido

Abra `public/index.html` no navegador para visualizar o sistema.

Esta versão roda em **modo demonstração**, sem exigir Firebase ou Mercado Pago:
- serviços aparecem normalmente;
- seleção de serviço;
- seleção de data;
- horários;
- formulário da cliente;
- Pix/cartão (interface);
- confirmação simulada.

O backend original foi preservado em `backend-original/`. Para produção, basta conectar o frontend novamente ao Firebase/Mercado Pago e configurar as credenciais.
